## 快速开始

### 安装与启动

本工具是一个 Streamlit Web 应用，运行在本地。启动方式:

```bash
cd "C:/Users/lenovos/Regression Analysis"
uv run streamlit run app/app.py
```

启动后，浏览器会自动打开 http://localhost:8501，进入应用主页。

### 支持的数据格式

| 格式 | 扩展名 | 编码 | 说明 |
|------|--------|------|------|
| CSV | `.csv` | UTF-8 / GBK 自动检测 | 推荐格式 |
| TSV | `.tsv` | UTF-8 / GBK | 制表符分隔 |
| TXT | `.txt` | UTF-8 / GBK | 逗号或制表符分隔 |
| Excel | `.xlsx` / `.xls` | N/A | 支持多 sheet（默认第一个） |

**文件大小限制**: 50 MB 以上发出警告，200 MB 以上阻止上传。

### 五个页面

工具包含五个功能页面，按工作流顺序排列:

1. **数据上传与预览** — 上传文件、查看数据摘要、管理变量类型
2. **数据探索** — 描述性统计、相关矩阵、分布图、缺失值处理、异常值检测
3. **模型设定** — 选择变量、配置模型、变量转换、交互项、运行回归
4. **回归结果** — 系数表、统计量、诊断图、多模型对比、假设检验
5. **导出与报告** — CSV/Excel/PNG/SVG/LaTeX/HTML/ZIP 多格式导出

## 案例 1: 房价影响因素分析

### 场景描述

某房地产研究团队需要分析影响房屋价格的关键因素。数据包含 500 套房屋的记录，变量包括面积、卧室数、房龄、位置评分、楼层、是否有车库等。

本案例将演示从数据加载到报告导出的完整流程。

### 步骤 1: 加载数据

1. 打开应用，进入 **数据上传与预览** 页面。
2. 点击 **加载快速示例数据集** 按钮（蓝色按钮，位于上传区域下方）。
3. 系统自动生成一个包含 500 行 8 列的模拟数据集。

**预期结果**:
- 页面右侧显示 "示例数据集已加载！"
- 显示数据摘要卡片: 行数 500、列数 8、内存占用量、编码 "N/A (模拟数据)"
- 下方展开 "变量信息" 按钮可查看每个变量的推断类型

> **[截图占位]**: 数据上传页面，右侧显示数据摘要卡片（行数、列数、内存、编码）和变量信息表。左侧显示文件上传区域和"加载快速示例数据集"按钮。

### 步骤 2: 数据探索

1. 切换到 **数据探索** 页面。
2. 查看 **描述性统计** 表格，了解各数值变量的均值、标准差、极值。
3. 查看 **相关系数矩阵** 热力图，了解变量间的线性相关程度。

**预期结果**:
- 描述性统计表显示 price、sqft、bedrooms、age 等变量的统计量
- 相关系数热力图以红蓝色阶显示变量间相关度（红色=正相关，蓝色=负相关）
- 可观察到 sqft 与 price 有较强的正相关

> **[截图占位]**: 数据探索页面，显示相关系数矩阵热力图（红蓝色阶，标注皮尔逊相关系数值）。

4. 在 **分类变量频率** 区域，选择 "bedrooms" 查看卧室数的分布饼图。

### 步骤 3: 模型设定

1. 切换到 **模型设定** 页面。
2. 在 **变量选择** 区域:
   - **因变量**: 选择 `price`（房价）
   - **自变量**: 勾选 `sqft`（面积）、`bedrooms`（卧室数）、`age`（房龄）、`location_score`（位置评分）、`floor`（楼层）、`has_garage`（是否有车库）
3. 在 **模型选项** 区域，保持默认设置:
   - 包含常数项: 是
   - 置信水平: 95%
   - 标准误类型: 普通标准误
   - 缺失值处理: 删除缺失行
4. 页面底部显示公式预览: `price ~ sqft + bedrooms + age + location_score + floor + has_garage`
5. 点击 **运行回归** 按钮。

**预期结果**:
- 显示 "回归模型运行成功！"
- 快速摘要显示 R-squared、Adj. R-squared、观测数
- 出现 "查看回归结果" 链接

> **[截图占位]**: 模型设定页面，变量选择器展开，因变量选择 price，多个自变量已勾选。底部显示公式预览和"运行回归"按钮。

### 步骤 4: 解读结果

1. 点击 "查看回归结果" 链接，或手动切换到 **回归结果** 页面。

#### 4.1 模型统计量

页面顶部显示模型统计量卡片:

| 指标 | 含义 | 期望范围 |
|------|------|---------|
| R² | 模型解释力 | 0-1，越高越好 |
| Adj. R² | 考虑变量数量的调整 R² | 0-1，越接近 R² 越好 |
| F 统计量 | 模型整体显著性 | p < 0.05 表示显著 |
| RMSE | 预测误差均方根 | 越小越好 |
| AIC / BIC | 模型信息准则 | 越低越好（模型对比用） |
| Log-Likelihood | 对数似然值 | 越高越好 |

**预期结果**:
- R² 约为 0.7-0.8（模拟数据，较高）
- F 统计量 p 值远小于 0.001

> **[截图占位]**: 模型统计量卡片网格，显示 R²、Adj-R²、F 统计量、N、AIC、BIC、Log-Likelihood、RMSE 八项指标。

#### 4.2 系数表解读

系数表以表格形式展示每个自变量的回归系数:

| 列名 | 含义 |
|------|------|
| 变量 | 自变量名称 + 显著性标记 |
| 系数 | 偏回归系数（其他变量固定时的边际效应） |
| 标准误 | 系数估计的标准误差 |
| t 值 | 系数的 t 检验统计量 |
| p 值 | 双侧检验的 p 值 |
| 95% CI | 95% 置信区间 |
| 显著性 | `***` p<0.01, `**` p<0.05, `*` p<0.1 |

**如何解读**:
- `sqft` 的系数（如 200）表示: 其他条件不变时，面积每增加 1 平方英尺，房价平均增加约 200 元
- p<0.01 的变量标 `***`，表示在 1% 水平上显著
- 绿色高亮行 = p<0.05，深绿色 = p<0.01

> **[截图占位]**: 系数表格，绿色/深绿色高亮显著变量，显著性星标清晰可见。

#### 4.3 模型摘要

展开 "模型摘要" 区域，查看自动生成的中文分析文本:

> 本研究报告了 OLS 回归结果，因变量为「price」。模型整体显著(F(6,485)=xxx.xx, p<0.001)。R²=0.xxxx，调整R²=0.xxxx，RMSE=xxxx.xx。AIC=xxxx.xx，BIC=xxxx.xx。有效样本量 N=492。

#### 4.4 诊断图

页面下半部分提供 5 个诊断图标签页:

- **散点图 + 回归线**: 展示因变量与单个自变量的关系
- **残差 vs 拟合值**: 检验线性假设和等方差性（散点均匀分布=良好）
- **Q-Q 图**: 检验残差正态性（点沿对角线分布=正态）
- **尺度-位置图**: 检验等方差性（平滑线水平=方差一致）
- **Cook's Distance**: 识别影响点（红色柱超过阈值=可能的异常点）

展开 "诊断总览面板 (2x2)" 可同时查看四个核心诊断图。

> **[截图占位]**: 诊断总览面板的 2x2 网格，包含残差图、Q-Q 图、尺度-位置图和 Cook's Distance 图。

### 步骤 5: 导出报告

1. 切换到 **导出与报告** 页面。
2. 在 **数据导出** 区域下载 CSV 或 Excel 格式的数据。
3. 在 **结果导出** 区域下载系数表（CSV/Excel）和模型摘要文本。
4. （可选）在回归结果页面点击 "保存为 PNG" 暂存诊断图，回到导出页面下载 PNG/SVG 格式图表。
5. 点击 **一键导出所有结果** 生成包含系数表、摘要和图表在内的综合 ZIP 包。

**导出格式汇总**:

| 导出类型 | 格式 | 用途 |
|---------|------|------|
| 数据 | CSV / Excel | 保存处理后的数据 |
| 系数表 | CSV / Excel | 用于论文表格制作 |
| 模型摘要 | TXT | 文本报告 |
| 诊断图 | PNG / SVG | 论文插图 |
| 综合报告 | ZIP | 所有结果打包 |
| LaTeX 表格 | .tex | 直接插入 LaTeX 论文 |
| HTML 报告 | .html | 自包含网页报告 |
| 复现包 | ZIP | 数据 + 配置 + reproduce.py |

## 案例 2: 员工满意度调查

### 场景描述

某企业 HR 部门进行员工满意度调查，收集了 400 名员工的数据，包括工资、教育水平、工作经验、性别、行业、周工时、司龄等信息。分析目标是:
1. 识别满意度的影响因素
2. 比较不同变量组合的模型
3. 探索教育水平与工作经验的交互效应
4. 使用稳健标准误处理可能的异方差

### 步骤 1: 加载工资数据

1. 在 **数据探索** 页面的左侧边栏中，找到 **示例数据** 区域。
2. 选择 "工资数据 (400行, 7列)"。
3. 点击 **加载** 按钮。

**预期结果**:
- 侧边栏显示 "已加载「工资数据」！"
- 页面中央显示描述性统计和相关系数矩阵

### 步骤 2: 处理缺失值

1. 在 **缺失值处理** expander 中查看缺失情况。
2. 数据中 `years_at_company` 列有 5 个缺失值（约 1.25%）。
3. 选择处理策略 "中位数填充 (Median)"。
4. 点击 **应用缺失值处理**。

**预期结果**:
- 显示 "缺失值处理完成！"
- 显示处理前后行数变化: 400 行 → 400 行（中位数填充不删除行）
- 缺失值由 5 个变为 0

> **[截图占位]**: 缺失值处理 expander，显示缺失分析表和策略选择器。

### 步骤 3: 运行多个模型进行对比

#### 模型 A: 基准模型

1. 切换到 **模型设定** 页面。
2. 变量选择:
   - **因变量**: `satisfaction`（满意度）
   - **自变量**: `income`（收入）、`education`（教育）、`experience`（经验）
3. 点击 **运行回归**。

**预期结果**: R² 约 0.3-0.4，income 和 education 显著。

#### 模型 B: 加入更多控制变量

1. 在 **多模型对比** 区域，点击 "添加对比模型"。
2. 在对比模型 1 中:
   - **因变量**: `satisfaction`
   - **自变量**: `income`、`education`、`experience`、`is_urban`（城市/农村）、`spending`（消费支出）
3. 点击 **运行所有模型**。

**预期结果**:
- 两个模型对比表显示: 模型 B 的 R² 应高于模型 A（加入更多变量后解释力提升）
- 但 Adj-R² 的提升幅度较小（新变量贡献有限）

> **[截图占位]**: 多模型对比系数表，两列分别显示模型 A 和模型 B 的系数（含标准误和显著性星标）。

### 步骤 4: 添加交互项

1. 保持变量选择不变。
2. 展开 **变量转换** expander。
3. 在交互项区域，选择 `income` 和 `education` 创建交互项。
4. 观察公式预览更新: `satisfaction ~ income + education + ... + income:education`
5. 点击 **运行回归**。

**解读交互项**: 如果交互项系数显著为正，说明教育水平越高，收入对满意度的正向效应越强（即高学历者收入增加带来的满意度提升更大）。

> **[截图占位]**: 变量转换 expander，显示交互项创建界面（两个下拉选择框 + 添加按钮）。

### 步骤 5: 使用稳健标准误

1. 在 **模型选项** 区域，将 "标准误类型" 从 "普通标准误" 改为 "HC1 (异方差稳健)"。
2. 重新运行回归。
3. 对比普通标准误与 HC1 标准误的差异:
   - 如果两者接近 → 无异方差问题
   - 如果 HC1 标准误明显更大 → 存在异方差，应使用稳健标准误

**预期结果**:
- 回归结果页面顶部显示 "标准误类型: HC1 (异方差稳健)"
- 系数表中标准误列的值可能相比普通标准误有变化

> **[截图占位]**: 模型控制面板，标准误类型下拉选择器展开，显示 HC0/HC1/HC2/HC3 选项。

### 步骤 6: 异常值检测

1. 回到 **数据探索** 页面。
2. 展开 **异常值检测** expander。
3. 选择数值变量 `income`、`spending`、`satisfaction`。
4. 检测方法选择 "IQR"（默认 1.5 倍）。
5. 勾选 "显示异常值行"。
6. 点击 **运行异常值检测**。

**预期结果**:
- 检测结果表显示每个变量的异常值数和异常率
- 勾选了 "显示异常值行" 后，下方表格高亮显示异常数据

## 案例 3: 政策效果评估

### 场景描述

政策分析师需要评估环境规制政策对工业污染减排的实际效果。数据包含 300 个地级市的横截面数据， 核心变量包括政策执行强度、人均 GDP、工业增加值占比、人口密度和所在区域。分析目标是:
1. 对偏态变量进行对数变换
2. 对连续变量进行中心化处理以增强交互项的可解释性
3. 检验多重共线性 (VIF)
4. 使用 Sample Gallery 快速预览类似场景

### 步骤 1: 使用 Sample Gallery 加载政策评估场景

1. 在 **数据上传与预览** 页面，向下滚动到 "示例数据分析场景库 (Sample Gallery)" 区域。
2. 浏览 5 个预设场景的卡片。
3. 找到 **环境规制政策减排效果评估** 卡片。
   - 标签: 政策评估、交互项、稳健标准误
   - 描述: 300 个地级市面板数据，含政策强度与产业结构交互项及地区固定效应
4. 点击卡片上的 **加载此场景** 按钮。

**预期结果**:
- 页面自动跳转到回归结果页面
- 顶部显示蓝色信息框 "示例数据，仅供功能演示 — 环境规制政策减排效果评估"
- 展开 "分析场景说明" 可阅读完整的分析叙事
- 展开 "本场景特点" 可查看场景的技术特征
- 系数表、统计量、诊断图全部自动生成

> **[截图占位]**: Sample Gallery 卡片网格，5 个场景卡片展示标题、描述和标签。鼠标悬停在"环境规制政策减排效果评估"卡片上。

### 步骤 2: 查看预计算模型结果

Gallery 场景已预计算 OLS 回归结果 (HC1 稳健标准误):

1. 查看 **模型统计量**: R-squared 约 0.59，说明政策变量和产业结构解释了约 59% 的减排变异。
2. 查看 **系数表**: 关注交互项 `policy_intensity:industrial_share` 的系数和显著性。
3. 查看 **系数可视化** 的 dot-whisker 图: 交互项的置信区间是否跨过零点。
4. 查看 **统计诊断** 区域:
   - VIF 诊断结果（检查各变量的 VIF 值）
   - Shapiro-Wilk 正态性检验
   - Durbin-Watson 自相关检验

> **[截图占位]**: 回归结果页面，系数 dot-whisker 图显示各变量的点估计和 95% 置信区间，交互项系数标红。

### 步骤 3: 手动添加变量转换

切换到 **模型设定** 页面，应用变量转换:

1. 展开 **变量转换** expander。
2. **对数变换**: 对 `gdp_per_capita` 应用 "log" 变换（收入变量通常右偏）。
3. **中心化**: 对 `policy_intensity` 应用 "center" 变换。
   - 中心化后，主效应表示在 `industrial_share` 均值处的边际效应
   - 这使交互项系数的解读更加直观
4. **对 `industrial_share` 也进行中心化**。
5. 观察公式预览更新:
   ```
   emission_reduction ~ center(policy_intensity) + log(gdp_per_capita) + center(industrial_share) + population_density + C(region)
   ```
6. 点击 **运行回归** 重新计算。

**对数变换的目的**: 将右偏分布的变量（如 GDP、人口密度）转换为近似正态，改善模型拟合和残差分布。

> **[截图占位]**: 变量转换 expander，每个变量旁有下拉选择框（无变换/对数/标准化/中心化/平方项）。

### 步骤 4: VIF 诊断与共线性检查

在 **回归结果** 页面的 **统计诊断** 区域:

1. 查看 VIF 诊断结果:
   - VIF < 5: 无严重共线性（正常字体）
   - VIF 5-10: 中等共线性（橙色警告）
   - VIF > 10: 严重共线性（红色警告，建议处理）

2. 展开 **假设检验详细报告** 查看完整诊断文本:
   - 多重共线性检查
   - 残差正态性 (Shapiro-Wilk)
   - 残差自相关 (Durbin-Watson)

3. 如果 `gdp_per_capita` 和 `population_density` 的 VIF 较高，可考虑:
   - 剔除其中一个变量
   - 使用对数变换降低相关性
   - 后续版本将支持岭回归作为替代方案

> **[截图占位]**: 统计诊断区域，VIF 表格中红色/橙色高亮高 VIF 变量，下方显示 Shapiro-Wilk 和 Durbin-Watson 检验结果。

### 步骤 5: 导出 LaTeX 报告

1. 切换到 **导出与报告** 页面。
2. 在 **LaTeX 表格导出** 区域:
   - 点击 "下载 LaTeX (.tex)" 获取单模型系数表
   - 点击 "LaTeX 预览" 标签查看表格代码
3. LaTeX 表格使用 booktabs 样式，可直接插入学术论文。

**LaTeX 表格示例** (预览显示内容):
```latex
\begin{table}[htbp]
\centering
\caption{回归分析结果表}
\label{tab:regression}
\begin{tabular}{lcccc}
\toprule
变量 & 系数 & 标准误 & t值 & p值 \\
\midrule
policy\_intensity & 1.2345 & 0.1234 & 10.00 & 0.000 *** \\
...
\bottomrule
\end{tabular}
\end{table}
```

### 步骤 6: 生成 HTML 报告

1. 在 **HTML 报告导出** 区域，先回到回归结果页面暂存诊断图（点击各图的 "保存为 PNG" 按钮）。
2. 回到导出页面，点击 **生成 HTML 报告**。
3. 点击 **下载 HTML 报告** — 报告为自包含文件，所有图表以 base64 内嵌。
4. 直接用浏览器打开 `.html` 文件，无需任何依赖。

### 步骤 7: 生成分析复现包

1. 在 **分析复现包导出** 区域，点击 **生成分析复现包 (ZIP)**。
2. 下载的 ZIP 包含:
   - `data_subset.csv` — 分析所用的数据子集
   - `model_config.json` — 模型配置（变量选择、转换、标准误类型）
   - `reproduce.py` — 复现脚本（可直接运行重新生成结果）

## 功能参考

### 变量类型系统

工具自动检测每列的变量类型，用户可在数据上传页手动覆盖:

| 类型 | 中文名称 | 识别规则 | 模型中的处理 |
|------|---------|---------|-------------|
| `continuous` | 连续型 | 浮点/整数, 唯一值 > 10 | 原样进入模型 |
| `categorical` | 分类型 | 字符串/整数, 唯一值 2-10 | 转为虚拟变量 (n-1) |
| `binary` | 二元型 | 整数 0/1 或 两个唯一值 | 原样或虚拟变量 |
| `id` | 标识符 | 唯一值占比 > 90%, 名称含 id/ID | 自动排除 |
| `text` | 文本型 | 字符串, 唯一值占比 > 50% | 自动排除 |
| `ordinal` | 有序型 | 用户手动覆盖 | 可设为连续或分类 |

### 变量转换

| 转换类型 | 代码表示 | 适用场景 |
|---------|---------|---------|
| 对数变换 | `log(var)` | 右偏变量（收入、GDP） |
| 标准化 | `standardize(var)` | 量纲统一，系数可比 |
| 中心化 | `center(var)` | 便于解释交互项 |
| 平方项 | `square(var)` | 非线性关系（U 型/倒 U 型） |
| 交互项 | `var1:var2` | 调节效应分析 |

### 标准误类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 普通标准误 | 经典 OLS 标准误 | 满足所有假设的理想数据 |
| HC0 | 异方差一致标准误 (基础版) | 一般异方差 |
| HC1 | 异方差一致标准误 (小样本修正) | 样本量 < 100 |
| HC2 | 异方差一致标准误 (杠杆值调整) | 杠杆值差异大 |
| HC3 | 异方差一致标准误 (Jackknife) | 小样本 + 高杠杆 |

### 缺失值处理

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 删除缺失行 (Drop) | 移除含任意缺失值的行 | 缺失 < 5% |
| 均值填充 (Mean) | 用列均值填充缺失值 | 连续变量，缺失 5-20% |
| 中位数填充 (Median) | 用列中位数填充缺失值 | 偏态变量，缺失 5-20% |

### 异常值检测

| 方法 | 参数 | 适用场景 |
|------|------|---------|
| IQR 法 | 倍数 (默认 1.5) | 一般检测，不假设分布 |
| Z-Score 法 | 阈值 (默认 3.0) | 近似正态分布的变量 |

### 诊断图表详解

| 图表 | 目的 | 良好模式 | 问题信号 |
|------|------|---------|---------|
| 残差 vs 拟合值 | 检验线性 + 等方差 | 散点均匀随机分布 | 漏斗形/曲线形 |

| 尺度-位置图 | 检验等方差性 | LOESS 线接近水平 | 线明显倾斜 |
| Cook's Distance | 识别影响点 | 大多数点低于 4/n 阈值 | 红色高柱 |

## 常见问题

### Q: 数据上传后显示乱码怎么办？
A: 工具自动检测 UTF-8 和 GBK 编码。如果自动检测失败，请用记事本或其他编辑器将 CSV 文件另存为 UTF-8 编码后重新上传。

### Q: 变量类型检测不准确怎么办？
A: 在数据上传页面的 "手动覆盖变量类型" expander 中，可以为每个变量重新指定类型（连续/分类/二元/ID/文本/有序）。

### Q: 为什么某些变量没有被加载到自变量选项中？
A: 被检测为 `id` 或 `text` 类型的变量会自动从候选列表中排除。如需使用这些变量，请先在数据上传页手动覆盖其类型。

### Q: R² 很高 (如 > 0.95) 是否意味着模型很好？
A: 不一定。极高的 R² 可能暗示过度拟合或变量间存在数学恒等关系。建议检查 VIF 诊断、Q-Q 图和残差图。

### Q: R² 很低 (如 < 0.1) 是否意味着分析失败？
A: 不一定。某些领域（如心理学、社会学调查数据）R² < 0.1 是常见现象。关键是看 F 检验是否显著，以及个别变量的系数是否显著。

### Q: 图表 PNG 导出失败？
A: PNG 导出依赖 kaleido 库。如果导出失败，请确保已安装:
```bash
uv pip install kaleido>=1.3.0
```
SVG 导出不依赖 kaleido，可作为替代方案。

### Q: 如何保存分析进度？
A: 工具的会话状态会在关闭浏览器后自动保存（JSON 序列化到 .session_cache）。重新打开浏览器时会提示恢复。如需长期保存，请使用导出功能下载数据和结果。

### Q: 为什么 "is_urban" 变量显示为 binary 类型？
A: 变量类型检测器会识别仅有两个唯一整数值（如 0 和 1）的列为二元变量。这是正常的。分类变量（如 "education" 有 5 个水平）会被识别为 categorical。

### Q: 交互项的主效应必须包含吗？
A: 是的。工具在添加交互项时，会自动保留主效应变量。这是计量经济学的标准做法，避免了遗漏变量偏误。
