## 版本安全评估

### streamlit 1.57.0
- **状态**：安全
- 最新稳定版为 1.57.x，项目使用最新的稳定主要版本。Streamlit 1.35+ 无已知高危漏洞。
- 建议：持续关注 Streamlit 安全公告 (https://github.com/streamlit/streamlit/security/advisories)

### pandas 3.0.3
- **状态**：安全
- Pandas 3.0.x 是最新主要版本。已在 2.x 系列修复了历史上与 pickle 反序列化相关的 CVE（CVE-2020-13091），本项目不涉及 pickle 反序列化。
- 建议：保持主版本更新。

### statsmodels 0.14.6
- **状态**：安全
- 0.14.x 是当前稳定系列。statsmodels 依赖链简单，历史上无严重 CVE 记录。
- 建议：关注 0.15.x 的发布以获取新特性支持。

### plotly 6.7.0
- **状态**：安全
- Plotly 6.x 是最新主要版本。历史上无严重安全漏洞记录。
- 注意：Plotly 生成的 HTML 中可能包含 JavaScript，仅在本地使用，不涉及 XSS 风险。

### openpyxl 3.1.5
- **状态**：安全
- 3.1.x 是当前稳定版。历史上曾有与 XML 实体展开相关的安全问题（CVE-2024-31992），已在 3.1.3+ 修复。当前版本 3.1.5 不受影响。

### kaleido 1.3.0
- **状态**：安全
- Kaleido 是 Plotly 的静态图像导出后端，v1.3.0 是最新稳定版。作为 Chromium 包装器，依赖系统级 Chromium 二进制，需保持更新。
- 建议：关注 kaleido 上游发布，及时升级以获取 Chromium 安全修补。

### jinja2 3.1.6
- **状态**：安全
- 3.1.x 系列已修复历史沙箱逃逸漏洞（CVE-2024-22195, CVE-2024-34064）。
- 本项目仅在 LaTeX 和 HTML 模板导出中使用 Jinja2，模板由代码控制，不接收用户输入的模板字符串，沙箱风险可控。

### numpy 2.4.6
- **状态**：安全
- 2.x 是最新主版本。NumPy 核心库历史上无严重的远程可利用漏洞。与 pickle 相关的风险（CVE-2019-6446）在允许从不受信任源加载数据时可能存在，本项目不使用该功能。

### scikit-learn 1.8.0
- **状态**：安全
- 1.8.x 是最新稳定版。历史上与模型持久化（pickle/joblib）相关的安全建议已有明确文档，项目不在不受信任环境中加载模型。

### requests 2.34.2 / urllib3 2.7.0 / certifi 2026.5.20
- **状态**：安全
- 均为当前稳定版本。certifi 已更新至 2026.5.20，CA 证书包是最新的。
- urllib3 2.x 系列已修复历史上与代理相关的漏洞（CVE-2023-45803）。
- requests 2.34.x 修复了 Cookie 相关的信息泄露风险（CVE-2024-45296，影响 < 2.32.0）。
- 注意：本项目不通过网络加载外部数据，所有数据处理均在本地完成。

## 安全建议

1. **定期审计**：建议每月运行 `pip-audit` 或类似工具扫描依赖
2. **自动化**：可将 `uv pip list --format=json` 结果脚本化，与 PyPA Advisory Database 对比
3. **最小权限**：已在 `pyproject.toml` 中明确列出依赖，未引入不必要的包
4. **用户输入**：项目不接收可直接执行的代码，所有用户输入均通过 Streamlit 内置的输入组件处理
5. **本地运行**：项目为纯本地工具，无网络暴露面，整体安全风险较低
